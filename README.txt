TITANS TACKLE — Public preview deployment

Files in this folder are a static website. Upload ALL files to your static web host or GitHub Pages repository root.

The public app links purchases to titanstackle.com; does not process checkout, provide owner access, or sync data. Catalog is a snapshot from October 16, 2026.

To publish via GitHub Pages: make a public repository, upload the folder files to repository root, then Settings > Pages > Deploy from a branch > main/(root). Wait for the Pages URL to be generated. To use app.titanstackle.com, first set custom domain in GitHub Pages, then set DNS CNAME in GoDaddy as GitHub documents. Do not upload secrets.

Weather, externally hosted images, and map links require a connection. Catch records and saved spinner designs reside in that device browser only.
